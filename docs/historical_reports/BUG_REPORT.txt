Feature: Student Attendance Scope
Reproduction: Logged in as a student, open attendance page. Query aggregates all attendance rows by student_id only: SELECT ... FROM attendance WHERE a.student_id = ? GROUP BY subject_id. There is no academic_year, semester, course, division, or enrollment filter.
Expected: Only current academic-period attendance should be displayed for the student's active enrollment context.
Actual: All historical and cross-semester attendance from different periods is blended into a single attendance percentage.

Reproduction: Student dashboard loads with $student['academic_year'] set by: SELECT year_name FROM academic_years WHERE status = 'Active' LIMIT 1; This bypasses the student's actual enrollment record.

Recommended Fix: Resolve academic year from student_academic_enrollments using student_id + status = Active, not from the global academic_years table by LIMIT 1.
